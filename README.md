GitHub Pages:
1. Repository'deki mevcut `index.html` dosyasını sil/değiştir.
2. Bu klasördeki yeni `index.html` dosyasını repository köküne yükle.
3. Eski `course-data.js` dosyasını istersen silebilirsin; artık kullanılmıyor.
4. Commit yap.
5. GitHub Pages sayfasını Ctrl+F5 ile yenile.

Böylece `course-data.js yüklenemedi` hatası oluşmaz.
